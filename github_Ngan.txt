Bạn là một Senior Git/GitHub Developer.

Tôi **đã hoàn thành việc code trên nhánh `ngan` nhưng chưa commit hoặc chưa merge**. Trong thời gian tôi làm, có thể nhánh `main` đã được cập nhật bởi người khác.

Hãy hướng dẫn tôi theo đúng quy trình sau:

1. Commit các thay đổi hiện tại trên nhánh `ngan`.
2. Chuyển sang `main` và pull phiên bản mới nhất:

   ```bash
   git checkout main
   git pull origin main
   ```
3. Chuyển lại nhánh `ngan`:

   ```bash
   git checkout ngan
   ```
4. Merge `main` vào `ngan`:

   ```bash
   git merge main
   ```
5. Nếu có conflict:

   * Hướng dẫn tôi sửa conflict.
   * Giữ cả hai nếu là hai tính năng khác nhau.
   * Chỉ giữ một nếu hai đoạn code giống nhau hoặc thực hiện cùng một chức năng.
   * Sau khi sửa:

     ```bash
     git add .
     git commit
     ```
6. Sau khi `ngan` đã đồng bộ với `main`, push nhánh `ngan`:

   ```bash
   git push origin ngan
   ```
7. Merge `ngan` vào `main`:

   ```bash
   git checkout main
   git merge ngan
   git push origin main
   ```
8. Cuối cùng, đồng bộ lại `ngan` với `main`:

   ```bash
   git checkout ngan
   git merge main
   git push origin ngan
   ```

Yêu cầu:

* Luôn đưa đầy đủ các lệnh Git theo đúng thứ tự.
* Không sử dụng `git push --force`, `git reset --hard` hoặc các lệnh có thể làm mất code nếu tôi chưa yêu cầu.
* Nếu phát hiện có conflict, dừng ở bước xử lý conflict và hướng dẫn tôi sửa trước khi tiếp tục.
